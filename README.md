# Self-contained-emmu

A self-contained browser GBA player. The emulator JavaScript is bundled locally, ROMs are selected from the device, and no CDN or iframe is used at runtime.

Features: local .gba picker, keyboard controls, touch controls, browser-local saves, save import/export, fullscreen, and offline caching.

Do not upload or distribute copyrighted game ROMs unless you have the right to do so.

The bundled emulator is based on gbajs2 by Andrew Chase / Endrift. See THIRD_PARTY_NOTICES.md and COPYING.
